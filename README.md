# antonin.mp3 — Artist Website

My personal artist/producer website. Wanted something dark and minimal that links to my music on Spotify and Apple Music. 

**Learned:** multilingual HTML, CSS variables, vanilla JS

## Pages

- **Home** — hero, biography, productions, contact
- **Datenschutz** / **Impressum** — GDPR legal pages

## Features

- Full-screen hero with social links (Instagram, YouTube, Spotify, Apple Music)
- Embedded Spotify playlists and YouTube videos
- Multi-language support 
- Contact form
- Visitor counter
