# antonin.mp3 — Artist Website

My personal artist/producer website. Wanted something dark and minimal that links to my music on Spotify and Apple Music. Built it in 4 languages (DE/EN/ES/TH) with a contact form.

**Learned:** multilingual HTML, CSS variables, vanilla JS

## Pages

- **Home** (`index.html`) — hero, biography, productions, contact
- **Datenschutz** / **Impressum** — GDPR legal pages

## Features

- Full-screen hero with social links (Instagram, YouTube, Spotify, Apple Music)
- Embedded Spotify playlists and YouTube videos
- Multi-language support (DE / EN / ES / TH)
- Contact form
- Visitor counter

## Tech stack

- Vanilla HTML · CSS custom properties · JavaScript
- Google Fonts (Space Grotesk, Space Mono)
- No build step

## Design

Dark minimalist aesthetic. Accent color `#00ddd4` (turquoise).

## Getting started

```bash
# No install needed
open index.html

# Or serve locally
npx serve .
```
